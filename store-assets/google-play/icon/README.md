# Icon Source Draft

This directory is for source notes and future output files for the Google Play app icon. Do not commit generated drafts unless they are intentionally prepared for review.

## Target output filename

`local-find-icon-512.png`

## Target size

512x512

## Recommended format

32-bit PNG with alpha

## Max size

1024 KB

## Concept

Simple phone plus ringing/signal motif.

The icon should read clearly as a local phone finder at small sizes. It should feel practical and calm, not like an anti-theft or security alarm product.

## Constraints

- No text inside icon.
- Legible at small size.
- Avoid shield or lock imagery unless the app is positioned as a security product.
- Avoid notification dot.
- Avoid download arrow.
- Avoid price, ranking, or promotional badge.
- Avoid Google Play badge or store imagery.
