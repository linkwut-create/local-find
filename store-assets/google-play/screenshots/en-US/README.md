# English Screenshot Capture Script

Capture these screenshots in English. Do not mix English and Simplified Chinese in this screenshot set.

## 01-find-me-service.png

Goal:

Show the phone can be made findable on the local network.

Required UI state:

Find Me / receiver mode visible.

Avoid:

- Private network identifiers.
- Real tokens.
- Notifications.
- Personal device names.

## 02-controller-devices.png

Goal:

Show controller device list / connected device control.

Required UI state:

Controller mode visible with a demo paired device or neutral placeholder.

Avoid:

- Real phone owner name.
- Real IP address.
- Private token.
- Real Wi-Fi SSID.

## 03-qr-pairing.png

Goal:

Show QR pairing / scanner flow.

Required UI state:

QR scanner or pairing screen visible.

Avoid:

- Real pairing secrets.
- Real QR token contents.
- Private controller IDs.

## 04-language-settings.png

Goal:

Show English / Simplified Chinese language switching.

Required UI state:

Language setting menu or selector visible.

Avoid:

- Mixed-language screenshot set unless preparing localized `zh-CN` assets.
- Extra marketing overlays that are not localized consistently.
